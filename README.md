# Calculator 
Creating a simple calculator with Python

# How the calculator works 
- User inputs their name
- The program ask whether their name is correct or not using a while loop with if statments
- Then the main program starts
- The program ask the user to input an operator (+,-,*,/,**,//)
- Once the operator is selected, the program calls the method from the calculator class and then the user have to input 2 numbers
- The operator uses a while loop and if statments, so the program will keep prompting the user to pick an operator.
- If the program doesn't recognise the operator, the program will the user to try again and if the user inputs 'end', the program stops with a goodbye message.
